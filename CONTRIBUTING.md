# Contributing

Issues and pull requests are welcome.

Before opening a pull request:

1. Keep each change focused on one problem.
2. Add or update tests for changed behaviour.
3. Run `go test ./...` and `go vet ./...`.
4. Update the README or documentation when commands, flags, or exit codes change.

Do not include local site exports, credentials, generated binaries, or machine-specific configuration in a pull request.
